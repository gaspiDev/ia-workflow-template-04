1. Example Database Usage

The "Alto Shopping" example database is provided for demonstration purposes. Please be aware that:

  • AI-driven queries are processed via OpenRouter.
  • There is a daily limit on the number of queries that can be processed.
  • Service availability may be affected once this limit is reached.

2. Security and Connection Strings

Security Disclaimer: If you choose to provide your own database connection string to explore your data, we treat this information with the utmost caution.

We do not store your connection strings permanently in our primary database unless explicitly requested for history persistence. They are used solely to establish a session-based connection to your data source. However, we recommend using read-only credentials with restricted permissions for maximum safety.

3. Responsibility

Users are responsible for the queries they execute. This tool provides direct access to database execution layers through an AI agent. Always verify the agent's proposed queries before execution if possible.
